# Chalo — Mobile App

Flutter app targeting Android and iOS.

## Setup

1. Install Flutter: https://docs.flutter.dev/get-started/install/macos
2. Run `flutter create .` in this directory to initialise the project
3. Run `flutter doctor` to verify your environment
